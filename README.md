# 🌤️ WeatherForcasts App

> **A real-time weather tracking application that automatically detects user location to deliver precise local temperatures and atmospheric conditions.**
>
> ----------------
>
> ## 🛠️ Tech Stack & Architecture

* **Language:** Kotlin
* **UI Framework:** XML
* **Navigation:** Navigation Component
* **Architecture:**  MVVM (Model-View-Intent)
* **Networking:** Retrofit
* **Location Services:** Fused Location Provider API
* **Asynchronous Programming:** Kotlin Coroutines & Flow
* **Local Caching:** Room Database / Shared preference
